# Security Policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Report it privately through
[GitHub's private vulnerability reporting](https://github.com/remigius42/skill-graft/security/advisories/new), not in a
public issue. Say what you ran, what happened, and which versions of skill-graft, APM and your agent harness you used.

## Threat model

[docs/security.md](docs/security.md) says what skill-graft defends against, where, and which risks it accepts. A report
of a risk listed there as residual is welcome if you found a way to make it worse than it says.
