# AGENTS.md

skill-graft builds a user's agent skills from other people's repositories: it computes the transitive hull of
the skills they ask for, vendors and patches them (renames included), and hands the result to
[APM](https://github.com/microsoft/apm) to deploy. Read `CONTEXT.md` (glossary; use its terms) and `docs/adr/`
before changing behavior. Until OpenSpec specs cover it, `docs/design.md` holds how it works.

## Git

- Conventional Commits (commitlint). No Co-Authored-By trailer.
- Remote `origin`: <https://github.com/remigius42/skill-graft>. Never push without asking.
- Work on a branch, never on main: one per OpenSpec change, `feat/opsx-<change-name>`.
- A release is the one branch outside OpenSpec, `release/v<version>`: follow
  [CONTRIBUTING.md](CONTRIBUTING.md#releasing).

## Workflow

- Changes go through OpenSpec: propose (proposal, design, specs, tasks), wait for approval, then apply
  test-first (red-green-refactor), one commit per task.
- A commit that changes what a user sees adds its entry to `CHANGELOG.md` under `[Unreleased]`; for an OpenSpec
  change, the archive commit does. Say what the user sees, in `CONTEXT.md`'s terms; refactors and tooling get none.
- Every commit passes the hooks: `git commit` runs them, so run `pre-commit run --all-files` yourself only after
  changing a hook's config. New words: add them, sorted, to `words` in `.cspell.yaml`.
- `.claude/` is generated by `openspec init`. Regenerate it rather than editing it.

## Python

- Python 3.11 or later, for `tomllib`. Runtime dependencies: the standard library and `tomlkit`, nothing else.
  Call `git` and `apm` as subprocesses; never import `apm_cli`, whose internals are not an API.
- `mypy --strict` and `ruff` run as pre-commit hooks, configured in `pyproject.toml`; by hand: `uv run mypy .`
- `src/skill_graft/` has four layers, top to bottom: `cli.py`, `commands/`, `pipeline/`, `infra/`. A module imports
  only its own layer and those below; `lint-imports` (pre-commit, contract in `pyproject.toml`) refuses the rest,
  and a module outside the four packages. Call a function tests replace with `monkeypatch.setattr` through its
  module (`vendor.vendor(...)`), or the patch misses the call.

## Tests

- `tests/` mirrors the layers: a test file sits in the layer of the module it is named after
  (`tests/<layer>/test_<module>.py`); end-to-end files named after a command `cli.py` runs itself, or a
  cross-cutting concern, go in `tests/cli/`. Shared helpers stay in `tests/conftest.py`.
- Never touch the real `~/.apm`, `~/.claude`, or `~/.agents`. Anything that runs `apm` sets `HOME` to a
  temporary directory.
- Fixture skills and source repositories are synthetic, built in the test. Do not copy real skills into the
  repository.
- `evals/` runs agents headless: opt-in, billed in tokens, never in hooks or CI. Run one only when asked.
